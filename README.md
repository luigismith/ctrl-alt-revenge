# Ctrl-Alt-Revenge

Il sito e la pubblicazione social (Instagram, YouTube Shorts) di **Ctrl-Alt-Revenge**, un platform d'azione in 2,5D ambientato a Taranto nel 2087, fatto in Unreal Engine 5 con personaggi che sembrano pupazzi da stop motion e set di cartone. Progetto personale, in sviluppo, non in vendita.

Il progetto del sistema è in [`PROGETTO.md`](PROGETTO.md).

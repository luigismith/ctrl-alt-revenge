Privacy

Last updated 15 November 2026.

This site collects no personal data. It has no forms, sets no cookies, runs no analytics or ads, and loads nothing from other sites: even the fonts are hosted here.

The site is hosted on GitHub Pages. GitHub logs visitors' IP addresses for security, under its own privacy statement.

The apps connected to Instagram and YouTube are only used to publish to the Ctrl-Alt-Revenge profiles. They don't read or keep other users' data. Comments are read in order to reply, and aren't stored anywhere else.

For any request, including data deletion, open an issue on the site's repository. See also the data deletion page.
